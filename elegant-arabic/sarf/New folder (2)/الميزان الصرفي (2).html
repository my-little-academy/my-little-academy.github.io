✨ أمثلة تطبيقية على وزن الكلمات

دَخَلَ
وزنها: فَعَلَ
التحليل: دَ = ف، خَ = ع، لَ = ل
عَالِمٌ
وزنها: فَاعِلٌ
التحليل: عَ = ف، ا = زيادة، لِ = ع، مٌ = ل
مَسْجِدٌ
وزنها: مَفْعِلٌ
التحليل: مَ = زيادة، سْ = ف، جِ = ع، دٌ = ل
انْكَسَرَ
وزنها: انْفَعَلَ
التحليل: انْ = زيادة، كَ = ف، سَ = ع، رَ = ل
اسْتَخْرَجَ
وزنها: اسْتَفْعَلَ
التحليل: اسْتَ = زيادة، خْ = ف، رَ = ع، جَ = ل
مُسْلِمٌ
وزنها: مُفْعِلٌ
التحليل: مُ = زيادة، سْ = ف، لِ = ع، مٌ = ل
